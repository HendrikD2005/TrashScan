# TrashScan
Project for "Intel AI Global Impact Competition 2025" that demonstrates a Proof of Concept (PoC) work for AI-assisted Trash detection and recycling recommendations to reduce climate damage.

## How it works
TrashScan uses computer vision to detect waste through a camera and provides recycling recommendations to help reduce environmental impact.

## Tech Stack
- Vue.js & Vuetify
- TypeScript
- Teachable Machine
